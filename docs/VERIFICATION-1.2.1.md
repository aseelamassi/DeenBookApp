# التحقق من Flutter 1.2.1+6

تاريخ التحقق: 5 نوفمبر 2026.

## البيئة والنتائج

استخدم الفحص Flutter 3.47.5 وDart 3.13.4 على Linux، مع ملف `pubspec.lock` المرفق دون تغيير إصدارات الحزم.

| الفحص | النتيجة |
| --- | --- |
| `flutter analyze --no-pub` | لا أخطاء أو تحذيرات أو ملاحظات تحليل |
| `flutter test --no-pub --reporter expanded` | نجح 111 اختباراً، بما فيها مقارنة الصور المحفوظة |
| `flutter build web --release --no-pub` | اكتمل البناء بنجاح، ونجح فحص Wasm الأولي |
| الواجهات | 17 شاشة بعرضي 320 و390 بكسل، والقائمة الجانبية والإجراءات السريعة |
| الحالات الصعبة | تكبير النص إلى 130%، أسماء طويلة، رصيد كبير، لوحة مفاتيح بارتفاع 280 بكسل، وبقاء زر الحفظ متاحاً |
| المعاينة | 21 صورة مولدة من Flutter، وجميع روابط `preview.html` صالحة |

## ما تغطيه الاختبارات

- الدخول الإلزامي، رقم الجوال، انتهاء الجلسة وتجديد التوكن، والرسائل عند فشل الاتصال.
- الحسابات الفارغة والتنقل بين الزبائن والموردين والأصناف وكشوف الحساب.
- حفظ الفواتير والخصم والمدفوع الفوري، دقة الكسور، منع احتساب الحوالات المعلّقة ضمن المقبوضات المؤكدة، والتوافق مع الخادم القديم.
- التخزين المحلي، عزل بيانات المحلات، طابور المزامنة، وإعادة المحاولة بنفس معرّف العملية.
- تصدير CSV مع الفواصل والأسطر العربية وحماية النصوص من صيغ جداول البيانات.
- طلب الحساب والخطط والمراجعة دون ادعاء إرسال الطلب أو تفعيل الاشتراك تلقائياً.
- تثبيت تاريخ الاشتراك في بيانات الاختبار حتى تبقى صور الواجهات قابلة للمقارنة بمرور الوقت؛ هذا لا يغيّر الاشتراكات الحقيقية.

## حدود التحقق

الاختبارات تستخدم استجابات API معزولة وبيانات مصطنعة. لم تُنشأ حسابات أو حركات مالية على الخادم الحي، ولم تُختبر جلسة إنتاج فعلية. لم يُبنَ APK ولم تُجرَ تجربة على جهاز Android أو iOS فعلي. لا يثبت نجاح اختبارات Flutter جاهزية الخادم أو الدفع الإلكتروني أو إدارة العاملين؛ تفاصيل الربط المتاح موضحة في `CHANGES-1.2.1.ar.md`.

## إعادة الفحص

من مجلد المشروع، بعد تجهيز Flutter:

```bash
flutter pub get
flutter analyze
flutter test
flutter build web --release
```

صور المقارنة أُنتجت على Linux بإصدار Flutter المذكور؛ قد يختلف تنقيط النص بين أنظمة التشغيل أو إصدارات المحرك. لا تستخدم `--update-goldens` لتجاوز اختلاف غير مفهوم؛ راجع الصورة أولاً. لتحديث المعاينات بعد تعديل بصري مقصود:

```bash
flutter test test/gemini_visual_test.dart --update-goldens
flutter test
```
