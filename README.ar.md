# دفتر الأمانة — تطبيق Flutter 1.1.2

تطبيق عربي باتجاه RTL مبني على تصميم دفتر الأمانة بالكحلي والبرتقالي وخط Cairo، ويتصل بالـAPI في مشروع **DeenBook-Backend-Readable**. لا يتضمن التطبيق حساباً تجريبياً أو بيانات زبائن وحركات جاهزة؛ تظهر البيانات من حساب المحل على الخادم فقط.

هذه النسخة تطبّق تغييرات [التصميم الأخير](https://share.gemini.google/LQL0iVXaf4RZ): توحيد القوائم، تفاصيل الفواتير والخصم، الحوالات المعلّقة، والرصيد بعد كل حركة. التفاصيل في [سجل التغييرات](docs/CHANGES-1.1.ar.md).

**إذا لم تطبق تحديث الـAPI السابق، راجع [api-update/README.ar.md](api-update/README.ar.md)** لتفعيل الميزات المالية الجديدة. يتضمن المجلد مصدر الخادم المعدّل وmigration إضافية وSQL للترقية. لا تحذف قاعدة البيانات أو migrations الخاصة بمشروعك.

## التشغيل

تم استخدام Flutter **3.47.7** وDart **3.13.5**. ثبّت Flutter وAndroid Studio لتشغيل Android، أو Xcode على macOS لتشغيل iOS.

من داخل مجلد المشروع:

على Windows، يمكن فحص الخادم ثم تشغيل التطبيق بملف PowerShell المرفق:

```powershell
.\Start-DeenBook.ps1 -CheckOnly
.\Start-DeenBook.ps1
```

الملف يفحص HTTPS قبل تشغيل Flutter، ويوقف التشغيل عند تعذّر الوصول مع توضيح السبب. يحتاج Flutter في `PATH` وجهازاً متصلاً أو محاكياً. أضف `-SupportPhone` متبوعاً برقم إدارة الاشتراكات الدولي الحقيقي بين علامتي اقتباس؛ عند تركه فارغاً يبقى طلب الاشتراك قابلاً للنسخ فقط. يمكن اختيار جهاز مثل `-Device chrome`. راجع [خطوات Windows](docs/CONNECTION-AND-SUBSCRIPTION.ar.md#تشغيل-windows-بأمر-واحد).

أو استخدم أوامر Flutter مباشرة:

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=https://api-deenbook.runasp.net
```

الرابط الافتراضي هو `https://api-deenbook.runasp.net`، بدون `/api` أو نقطة في النهاية. التطبيق يضيف مسار `/api` لكل طلب؛ كما يصحح لاحقة `/api` أو `/api.` عند نسخها بالخطأ. لا يتضمن التطبيق أي بيانات دخول. راجع [إصلاح الاتصال والاشتراك](docs/CONNECTION-AND-SUBSCRIPTION.ar.md) قبل الاختبار على الاستضافة.

لـAndroid Emulator والخادم المحلي على الحاسوب:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:5043
```

يجب أن يكون الـAPI شغالاً على منفذ HTTP 5043. `localhost` داخل محاكي Android يشير إلى المحاكي نفسه. على جهاز حقيقي استخدم عنوان خادم يستطيع الجهاز الوصول إليه. إصدار Release يقبل HTTPS فقط ولا يتجاوز أخطاء شهادات TLS.

لإضافة رقم واتساب إدارة الاشتراكات بالصيغة الدولية:

```bash
flutter run --dart-define=API_BASE_URL=https://api-deenbook.runasp.net --dart-define=SUPPORT_PHONE=970XXXXXXXXX
```

استبدل رقم المثال برقم الإدارة الحقيقي. يدعم الإعداد الصيغة الدولية مع أو بدون `+`. زر المتابعة يفتح مسودة واتساب؛ يجب على المستخدم الضغط على إرسال داخل واتساب. عند غياب الرقم أو تعذّر فتح واتساب، تظهر عبارة «لم يُرسل الطلب»، ولا يُنسخ شيء إلا باختيار «نسخ التفاصيل». النسخ لا ينشئ حساباً أو طلباً على الخادم.

## ما يعمل

- الدخول الإلزامي برقم الجوال وكلمة المرور، وتوحيد الأرقام العربية والمحلية والدولية. قيد تفرد الرقم يفرضه الخادم.
- Refresh Token دوّار، مع تجديد واحد للطلبات المتزامنة وحفظه في التخزين الآمن. Access Token في الذاكرة.
- حالات الحساب الجديد الفارغة، ملخص الذمم، أحدث الحركات، الزبائن والموردون، البحث والفلاتر وتحميل صفحات إضافية.
- مورد بالاسم فقط، وتصنيف اختياري؛ بدون حقل وسائل الدفع المقبولة في الواجهة.
- الدين والمشتريات والدفعات والمرتجعات. لا تظهر الشيكات في خيارات الدفع.
- مسودة مالية محفوظة قبل الإرسال، وإعادة المحاولة بنفس `operationId` والبيانات لتجنب تكرار الحركة.
- كشف حساب مع تاريخ وطباعة PDF بالعربية. التقارير والسجل الكامل والنسخة الاحتياطية JSON.
- الأصناف وأسعار البيع والشراء. هذا الـAPI لا يتتبع كميات مخزون.
- إملاء وصف الحركة بالصوت، مع المراجعة والحفظ اليدوي.
- بيانات المحل وتغيير كلمة المرور والاشتراك من قائمة البروفايل.
- إحصاءات الزبائن والموردين وترتيبهم حسب الرصيد أو الاسم أو آخر حركة، وبيانات تواصل إضافية واتفاق دفع اختياري.
- فاتورة مبلغ مباشر أو أصناف بكميات حتى 3 منازل عشرية، وخصم ومدفوع فوري وحساب الباقي، مع أسعار ثابتة للفواتير السابقة.
- دفعة غير نقدية معلّقة لا تغيّر الرصيد قبل تأكيد الوصول من الخادم، مع مشاركة مسودة إيصال اختيارية.
- فلاتر سجل الحركات وإجماليات جميع النتائج المطابقة، وتصنيفات الأصناف، وطباعة عربية تتحمل الفواتير الطويلة.

الميزات الجديدة تُفعّل بعد أن يعيد الخادم `ledgerVersion: 2` من `/api/capabilities`. الخادم القديم يحتفظ بتدفقه السابق دون إرسال حقول لا يدعمها؛ مسودة جديدة محفوظة على الجهاز لا يعاد إرسالها إلى خادم قديم.

## الاشتراكات والحسابات

خطتان ظاهرتان: **60 شيكل لشهر** أو **150 شيكل لثلاثة أشهر**. حالة الاشتراك وصلاحيته تؤخذ من `GET /api/subscription`. لا يستطيع التطبيق تمديد الاشتراك محلياً.

الـAPI الموجود يوفر دخول صاحب المحل، لكنه **لا يوفر حالياً** تسجيل مستخدم جديد ذاتياً، أو إضافة العاملين وصلاحياتهم، أو بوابة دفع، أو استعادة كلمة المرور ذاتياً. لذلك:

1. تُنشئ الإدارة الحساب ورقم الجوال الفريد من لوحة الإدارة الحالية.
2. طلب الاشتراك/التجديد في التطبيق هو طلب تواصل، وليس عملية دفع إلكتروني أو تفعيل تلقائي.
3. شاشة العاملين في البروفايل توضح أنها غير متاحة بعد؛ لا توجد حسابات عاملين وهمية.
4. استعادة الوصول تتم عبر التواصل مع الإدارة. تغيير كلمة المرور متاح لمن دخل بالفعل.

إكمال هذه الميزات يحتاج توسيع الخادم أولاً. انظر `docs/API-INTEGRATION.ar.md`.

## إصدار Android

يجب إعداد مفتاح توقيع خاص بك. انسخ `android/key.properties.example` إلى `android/key.properties` واضبط مكان المفتاح وكلمات مروره محلياً. لا ترفع هذه الملفات إلى Git.

```bash
flutter build appbundle --release --dart-define=API_BASE_URL=https://api-deenbook.runasp.net
```

لا يُستخدم مفتاح debug لتوقيع Release. اسم الحزمة الحالي `com.deenbook.deenbook`؛ راجعه قبل النشر في المتجر.

## إصدار iOS

على macOS افتح `ios/Runner.xcworkspace`، واختر فريق Apple والتوقيع وBundle Identifier. إعدادات Keychain والميكروفون والتعرف على الكلام مرفقة. جرّب الدخول واستعادة الجلسة والإملاء والطباعة والمشاركة على جهاز حقيقي قبل النشر.

```bash
flutter build ipa --release --dart-define=API_BASE_URL=https://api-deenbook.runasp.net
```

## نسخة الويب

مرفقة لأغراض المعاينة والتطوير. يلزم HTTPS وضبط CORS على الـAPI للنطاق الفعلي. التخزين الآمن على الويب يختلف عن Keychain/Keystore على الهاتف، فلا يعادل حماية التطبيق الأصلي.

```bash
flutter run -d chrome --dart-define=API_BASE_URL=https://api-deenbook.runasp.net
```

لا تشغّل migrations من Flutter. قاعدة البيانات ومفاتيح توقيع JWT ومدة التوكن تظل في إعدادات الخادم.
