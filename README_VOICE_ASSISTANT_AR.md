# DeenBook – المساعد الصوتي المحلي (2026-11-28)

هذه نسخة مشروع Flutter كاملة (Source Code)، وليست APK مترجمة. لم تتغير إعدادات
المشروع أو رابط API أو pubspec/Gradle أو الـ Backend. تم دمج إصلاح التقارير
وبطاقات الحسابات السابق كما هو.

## طريقة الاستخدام
- من الرئيسية اضغط الميكروفون، ثم اضغط «اضغط وتكلم» أو اكتب الأمر.
- راجع النص الناتج. اضغط «تحليل الأمر». يمكن تغيير نوع الحركة إذا لزم.
- راجع الحساب والأصناف والمبالغ، ثم «تعبئة نموذج الحركة».
- أكمل أي بيانات ناقصة واختر الحساب/الصنف المكرر من النموذج الحالي.
- اضغط زر حفظ الحركة العادي بعد المراجعة. لا يقوم المساعد بالحفظ تلقائياً.
- من بطاقة الحساب أو شاشة الحركة يمكن فتح المساعد مع نوع الحركة والحساب المحددين.

## أمثلة
- يوسف اشترى مني بعشرة شيكل
- حط على يوسف خمسة وعشرين شيكل
- يوسف أخذ نص كيلو جبنة وحبتين حليب
- يوسف أخذ جبنة بعشرة شيكل
- يوسف أخذ أغراض بثلاثين ودفع عشرة
- يوسف دفعلي خمسين شيكل
- يوسف حوللي خمسين شيكل عالبنك ولسه ما وصل
- اشتريت من المورد أحمد بضاعة بمية شيكل
- اشتريت من المورد أحمد كيلو سكر بسعر خمسة
- دفعت للمورد أحمد ميتين

## حدود النسخة
- لا يوجد أي AI API أو مفتاح مدفوع. تستخدم SpeechToText الموجودة سابقاً.
- التعرف على الصوت نفسه يعتمد على محرك الهاتف واللغة العربية المتاحة؛
  عند عدم توفر الاتصال يحاول وضع onDevice. يمكن كتابة الأمر إذا لم يعمل الصوت.
- التحليل محلي بقواعد وليس نموذج فهم لغة عاماً؛ لا يمكن ضمان فهم كل جملة.
- يستخدم الحسابات والأصناف المحفوظة في الـ API/cache الحالية. المطابقة التقريبية
  للأسماء تقدم اقتراحات فقط؛ الاسم المكرر أو غير المعروف يتطلب اختياراً يدوياً.
- لا يُخمن سعر الجملة من سعر البيع. للمورد صيغة كمية + اسم + «بسعر» + سعر الوحدة.
  عند عدم وضوح العبوات أو الأسعار يجب تعديلها. التاريخ والخصومات غير المستخرجة
  تراجع يدوياً حسب آلية الشاشة الحالية.
- إنشاء الحسابات والأصناف والاستعلامات الصوتية عن الأرصدة ليست ضمن هذه النسخة.
- الاختبارات المضافة لم تُشغل: Flutter/Dart SDK غير متوفر في بيئة إعداد الملفات.
  يجب إجراء flutter analyze وflutter test وتجربة الميكروفون على هاتف فعلي قبل إصدار APK.

## تشغيل وفحص
من مجلد المشروع:
```
flutter pub get
flutter analyze
flutter test test/voice_command_test.dart
flutter test test/ledger_response_regression_test.dart
flutter test
flutter run
flutter build apk --release
```
لا تحذف التطبيق ولا تمسح بياناته قبل مزامنة العمليات المحلية.
ملفات البناء المؤقتة (.dart_tool، build، .gradle) غير مرفقة؛ يعاد توليدها.
