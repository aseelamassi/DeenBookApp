# إصلاح TC-55 وTC-56 — 21 نوفمبر 2026

## TC-55 — إدخال أسعار الأصناف

- عند إضافة صنف جديد، يبدأ سعر البيع وسعر الشراء **فارغين** بدل `0`.
- عند تعديل صنف موجود، إذا كان سعره صفرًا يظهر الحقل فارغًا؛ وإذا كان له سعر موجب يبقى السعر الحالي ظاهرًا.
- لا يمكن حفظ صنف دون اسم، أو بسعر بيع فارغ أو صفر أو سالب.
- سعر الشراء اختياري؛ تركه فارغًا يحفظه كـ`0` من دون حدوث خطأ أثناء التحويل الرقمي.
- تظهر رسالة التحقق في النموذج ولا يُغلق عند الإدخال غير الصالح.

## TC-56 — حاسبة الوزن والسعر

- رفض صفر/نص/مدخلات غير رقمية والوزن/المبلغ الكبير جدًا.
- في الحركات الموزونة الواحدة، اختير حد حماية **100 كغم** أو **10,000 شيكل**؛ وهذه حدود مقترحة قابلة للتعديل في منطق التحقق إذا تطلّبت طبيعة المحل ذلك، وليست سقفًا للزبون أو المورد أو رصيد المحل.
- وضع الغرامات يقبل أرقامًا صحيحة فقط، ووضع الكيلو يقبل حتى ثلاث خانات عشرية، والمبالغ حتى خانتين عشريتين.
- عند رفض القيمة تظهر رسالة عربية مفهومة، ويُعرض وزن 0 غرام ومبلغ 0 بأمان، ويصبح زر «إضافة للفاتورة» غير نشط.
- تبقى حاسبة الأوزان الأصلية والتحويل بين مبلغ/وزن للمدخلات الصحيحة دون تغيير.
