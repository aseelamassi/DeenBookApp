# إصلاح إخفاء الحقول عند فتح لوحة المفاتيح — 13 نوفمبر 2026

## المشكلة
عند فتح نافذة إضافة زبون أو مورد أو صنف، كان نموذج الـ Bottom Sheet يحدد ارتفاعه حسب الشاشة الكاملة (78%) ثم يضيف مسافة لوحة المفاتيح. داخل النافذة، كان Scaffold يخصم ارتفاع لوحة المفاتيح مرة ثانية؛ فتختفي أغلب حقول الإدخال ويظهر فراغ واسع.

## التعديل
- `lib/ui/widgets.dart`: احتساب ارتفاع النافذة من المساحة المتاحة فوق لوحة المفاتيح، وتمرير `MediaQuery.removeViewInsets(removeBottom: true)` إلى داخل النموذج حتى لا يخصم ارتفاع لوحة المفاتيح مرة ثانية.
- `lib/features/catalog.dart`: السماح بإغلاق لوحة المفاتيح بالسحب في قوائم إضافة/تعديل زبون، مورد، وصنف.
- `test/modal_keyboard_test.dart`: فحص فتح لوحة المفاتيح داخل النماذج الثلاثة وإمكان الوصول لزر الحفظ بالتمرير.

## الثوابت
- لم يتم تعديل ملف إعدادات أو باكيجات أو رابط API أو إعدادات Android/iOS.
- لم يتغير منطق حفظ البيانات في الـ Backend.

## اختبار الجهاز المطلوب
1. فتح إضافة زبون وكتابة الاسم مع لوحة المفاتيح العربية والتأكد من ظهور الحقول بالتمرير.
2. تجربة جميع الحقول وزر الحفظ في إضافة مورد وصنف.
3. تجربة شاشة صغيرة والشاشة الأفقية ولوحة مفاتيح Gboard وSamsung.

## حالة الاختبار
الاختبار الآلي موجود في المصدر، لكن لم ينفّذ هنا بسبب عدم توفر Flutter SDK.
