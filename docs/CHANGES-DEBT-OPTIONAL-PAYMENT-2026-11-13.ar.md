# تحديث شاشة تسجيل مشتريات (دين) — 13 نوفمبر 2026

## المطلوب والمنفذ

- تحسين المسافة بين عنوان القسم والمحتوى لتجنب تداخل النصوص مع حدود حقل الإدخال.
- تغيير عنوان القسم إلى: «دفعة مع المشتريات (اختياري)».
- حذف حقل الخصم وحقل رقم الفاتورة **من واجهة تسجيل مشتريات الزبون فقط**.
- حقل «المبلغ المدفوع من الزبون — شيكل» يبدأ فارغًا، بدون 0.
- ترك الحقل فارغًا لا يمنع حفظ حركة الدين؛ يُرسَل `paidNow: 0`.
- الدفعة المدخلة فعليًا تبقى ضمن واجهة وسيلة الدفع والحسابات الموجودة.
- تفاصيل فاتورة المورد وصفحة السداد لم تُمس ضمن هذا التعديل.

## التوافق والإعدادات

- لا تعديل على API أو Backend أو قاعدة البيانات أو Migration.
- لا تغيير على `pubspec.yaml` أو `pubspec.lock` أو ملف `codemagic.yaml` أو إعدادات Android/iOS أو رابط الـ API.
- ملف Flutter الوحيد المعدّل: `lib/features/transaction.dart`.
- اختبار Flutter المحدّث: `test/modern_ui_test.dart`.

## التحقق قبل النشر

شغّل `flutter analyze` و`flutter test test/modern_ui_test.dart`، ثم جرّب حفظ دين دون دفعة، وحفظ دين مع دفعة نقدية. بيئة إعداد هذا التعديل لا تحتوي Flutter SDK، لذا لم تُشغّل اختبارات Flutter فيها.
