DeenBook — حزمة مصدرية تراكمية كاملة للاختبار (غير معتمدة للنشر)

النسخة تجمع المشروع الأصلي والحزمة التراكمية Offline Catalog والتعديلات الجديدة. لا حاجة لإعادة تركيب الحزم السابقة.
- إضافة العامل محلياً بمعرف ثابت؛ كلمة المرور تحفظ مؤقتاً في FlutterSecureStorage ضمن طابور المستخدم حتى اعتماد الطلب أو إلغائه. لا يستطيع العامل تسجيل الدخول لأول مرة أو إدارة حسابه المحلي المعلق قبل اعتماد الخادم.
- طلبات شطب وتأكيد الحركات التي سبق تنزيلها: حفظ دائم، منع تكرار الطلب المحلي، وإظهار حالة انتظار اعتماد الخادم. لا تُعدّل الأرصدة المؤكدة قبل الاعتماد. الحركة التي لم تصل إلى الخادم بعد لا يمكن شطبها أو تأكيدها بهذا المسار.
- تقارير وCSV/PDF وملخص مشاركة من السجلات المتزامنة المخزنة، مع تنبيه دائم إلى احتمال النقص أو القدم. لا تشمل هذه الصادرات الحركات الجديدة غير المعتمدة. الطباعة والمشاركة تتأثر بتوفر خدمات الجهاز وتطبيقاته.
- إصلاح فلترة الفترة بالتوقيت UTC، وتخزين نتائج الحركات وكشوف الحسابات، وإزالة آلية إقرار الحركة بمطابقة جزئية غير كافية.
- بقيت مدة السماح 1–7 أيام حسب سياسة المحل في الإدارة، ولا يطبق تغييرها على الجهاز دون اتصال ناجح.
- الحد الأدنى المستهدف Android 7 (API 24) أو الحد الأدنى الأعلى الذي يفرضه Flutter؛ Target API 36. لم تُغيّر إعدادات البناء أو مكتبات المشروع في هذه الجولة.

الحدود: لم يتم ترحيل تخزين JSON/SecureStorage إلى SQLite. لا يوجد ضمان للتقارير الكاملة عند نقص البيانات المحلية أو حصول تعارض بين الأجهزة؛ لا تزال اختبارات الذرية وتوقف التطبيق أثناء إقرار العمليات ومراجعة الحركات القديمة معلقة. التسجيل الأول وتفعيل الاشتراك يتطلبان اتصالاً. لم يتم اختبار SDK أو أجهزة قديمة أو إنتاج AAB.

قبل النشر: flutter pub get ثم flutter analyze ثم flutter test. اختبر تحديث التطبيق الحالي دون حذفه، انقطاع الشبكة وإعادة التشغيل، تكرار الطلب، تبديل الحسابات، امتلاء الذاكرة، Android 7/8/9 وأجهزة 32-bit. افحص merged manifest و16KB compatibility. إصدار Google Play يحتاج توقيع الإصدار الخاص بك، تحقق من versionCode، سياسة الخصوصية، حذف الحساب والبيانات، Data Safety، وسياسة الدفع. لا ترفع الحزمة إلى الإنتاج دون اجتياز الاختبارات.
