# إصدار مصدر DeenBook المجمّع — 21 نوفمبر 2026

## المحتوى
هذا الإصدار يجمع نسخة Flutter الأخيرة (TC-55 وTC-56) مع تعديلات هذا الطلب، وكذلك تحديثات Backend المعتمدة من الحزم السابقة: تعديل طلب تفعيل قيد المراجعة، صورة فاتورة المورد، شطب الحركات دون حذفها، مرتجعات المورد وإحصاءات التقرير، وسائل التحصيل المتعددة، حسابات العاملين، التحقق من أرقام هواتف الحسابات، سقف دين الزبون، وتسعير الأصناف بالوزن.

### ملاحظات الاختبارات الحالية
- **TC-02**: صفحة دخول واحدة للمالك والعامل؛ يعتمد الاسم المعروض على هوية المستخدم الذي سجّل الدخول. يجب إعادة الاختبار على الجهاز.
- **TC-15**: بعد تأكيد وصول الحوالة، يتم تحديث بيانات الحركة المعروضة فورًا وإعادة جلب الإحصائيات دون الخروج من الصفحة.
- **TC-26**: حاسبة الفكّة لم تعد تظهر داخل دفعة نقدية مصاحبة لعملية مشتريات؛ تبقى متاحة في شاشة قبض دفعة مستقلة.
- **TC-30**: تمت إضافة فلاتر حالة الحساب/فئات الموردين، وتوحيد شكل قسم كشف الزبون مع كشف المورد مع المحافظة على الإجراءات الأصلية.
- **TC-38**: إلغاء التقاط الصورة أو عدم توفر الكاميرا لا يمنع حفظ الفاتورة بلا صورة. عند تشغيل كاميرا خارجية قد لا تظهر نافذة صلاحية داخل DeenBook، ويختلف ذلك حسب نظام الجهاز.
- **TC-60**: التطبيق لا يدعم استيراد JSON لاستعادة الحساب؛ التصدير أرشيف اختياري، والاستعادة المعتمدة تتم بتسجيل الدخول على الجهاز الجديد بعد مزامنة بيانات الجهاز القديم. يجب تعديل هذا الاختبار ليقيس الاستعادة عبر السيرفر بدل إدخال JSON غير صالح.

## نشر Backend
1. **احفظ نسخة احتياطية** من قاعدة البيانات قبل أي ترحيل.
2. قارن مجلد المشروع هذا بأحدث Backend لديك قبل النشر، خاصة إذا أجريت تعديلات منفصلة محليًا منذ استلام الحزم السابقة.
3. أنشئت ملفات ترحيل للميزات التي كانت موجودة في كود Flutter دون وجودها كاملة في المصدر المرجعي: سقف الدين، تسعير الوزن، صورة الفاتورة، وسائل التحصيل، واسم العامل. هناك أيضًا Migration سابقة للتسجيل/العاملين.
4. **راجع جدول `__EFMigrationsHistory` والأعمدة الفعلية** قبل تنفيذ `dotnet ef database update`، لأن الأعمدة ربما أضيفت يدويًا أو من مشروع أحدث؛ تشغيل migration مكررة يمكن أن يفشل.
5. افحص البناء والاختبارات والترحيلات على قاعدة اختبار أولًا، ثم انشر Backend وطبّق Flutter بعد نجاحه.
6. لا توجد تغييرات مقصودة على إعدادات المشروع أو `appsettings.json` أو روابط API أو `pubspec.yaml` أو Gradle. لا يتم تشغيل ترحيلات تلقائيًا بهذا التسليم.

## تشغيل Flutter
احتفظ بملفات الخطوط الثنائية الأصلية (`assets/fonts/*.ttf`) من مشروعك الحالي، فهي **غير مرفقة** في ZIP. تُستخدم إعداداتك الأصلية دون تعديل.
أجرِ `flutter pub get`, `flutter analyze`, `flutter test`, ثم بناء التطبيق وتجربة الحالات TC-02/15/26/30/38/60 على هاتف حقيقي.

## مستوى التحقق
أُجريت مراجعة ملفات وفروقات وفحص ZIP واختبارات اتساق ثابتة. **لم يتم تشغيل Flutter أو .NET Build أو الاختبارات فعليًا** بسبب عدم توفر SDKs في بيئة إعداد الملفات؛ هذه نسخة مصدر مجمّعة *جاهزة للبناء والاختبار* وليست إصدار إنتاج معتمدًا.
