# إصلاح رسالة خطأ تغيير كلمة المرور

- إصلاح ظهور `Incorrect password.` بالإنجليزية عند إدخال كلمة المرور الحالية بشكل خاطئ.
- تعرض شاشة تغيير كلمة المرور الآن: `كلمة المرور الحالية غير صحيحة. تأكد منها وحاول مرة أخرى.`
- تنسيق رسالة الخطأ باللون الأحمر، ومسح الرسالة السابقة عند إعادة المحاولة.
- بقية رسائل الأخطاء تظل كما يعيدها الخادم لتسهيل التشخيص.
- لم تتغير طريقة التحقق من كلمة المرور أو أي API أو Configuration أو Package.
- اختبار جديد: `test/password_change_error_test.dart`.

## طريقة استخدام الباتش
انسخ `lib/features/profile.dart` من ملف الباتش إلى المجلد نفسه في مشروعك، وأضف ملف الاختبار إن أردت.
