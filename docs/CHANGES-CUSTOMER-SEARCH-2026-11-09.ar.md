# إصلاح اختيار الزبون داخل تسجيل مشتريات الدين — 9 نوفمبر 2026

## ما تغيّر
- استبدال اختيار الزبون/المورد في `lib/features/transaction.dart` بالحقل الجديد `PartyLookupField`، بدل أي انتقال إلى صفحة الزبائن.
- بالضغط على الحقل أو سهم القائمة تظهر الأسماء أسفله ضمن نفس شاشة التسجيل، ويمكن كتابة الاسم لتصفية النتائج أثناء الكتابة.
- عند اختيار اسم، يحتفظ النموذج بمعرّف الزبون `id` الفعلي؛ إذا غُيّر النص تُلغى هوية الزبون السابق ولا يسمح بإرسال الحركة على حساب خطأ.
- تظهر أسماء الزبائن مع رقم الجوال والاسم المختصر للتفريق بين الأسماء المتشابهة؛ وتظهر رسائل واضحة لحالة التحميل، عدم وجود نتائج، وفشل الاتصال.
- خيار البحث نفسه يعمل عند تسجيل الدفعات أو فواتير الموردين عند الحاجة، من دون تغيير مسارات هذه الشاشات الأخرى.
- أضفنا `test/party_lookup_field_test.dart` لاختبار البحث والاختيار وإلغاء الاختيار القديم.

## Backend
- لا يلزم تعديل الـ Backend: يتم استخدام واجهة البحث الموجودة أصلًا:
  `GET /api/customers?search=<name>&sort=name&page=1&size=30`
  و`GET /api/suppliers` عند التعامل مع المورد.
- الـ Backend ينفذ البحث في الاسم والاسم المختصر والهاتف بالفعل.

## الإعدادات
لم يتغير `pubspec.yaml` أو `pubspec.lock` أو عنوان الـ API أو أي إعداد Android/iOS أو إعداد Backend؛ ولا توجد Migration مطلوبة لهذا التغيير.

## التحقق المطلوب محليًا
```bash
flutter pub get
flutter analyze
flutter test test/party_lookup_field_test.dart
```

ثم اختبار الاختيار من شاشة «تسجيل مشتريات (دين)» على الهاتف: اضغط الحقل، ابحث عن اسم، اختره، أدخل المبلغ واحفظ الحركة؛ يجب البقاء في نفس الشاشة حتى الحفظ.
